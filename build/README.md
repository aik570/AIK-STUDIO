# AIK Studio website

Premium websites for ambitious businesses. English first, German at `/de/`.

The visual system follows `docs/aik-studio/visual-identity-v1.md`: palette (§3), type (§4), motion (§8) and website application (§9).

The A135 Langley listing in the repository root is a separate portfolio piece. It is not part of this site.

## Stack

Plain HTML, CSS and JavaScript. No framework, no build step and no third-party requests.

```
index.html              English homepage
de/index.html           German homepage (same structure)
css/site.css            tokens, base, components
css/hero-flight.css     cinematic opening, header over the scene, hand-over to #work
css/work.css            Selected Work (#work), scroll-linked drift of the MA'LOA photograph and the fog
css/sections.css        Services, Approach, About, Contact, footer
js/site.js              header state, mobile menu, pending nav links, fitted type, contact address
js/hero-flight.js       the opening: logo → light reveal → film → Hero → scroll hand-over
js/work.js              reveals for every section below the Hero (off with reduced motion)
prototypes/             Selected Work experiments A and B (not linked, never deployed)
tests/                  Playwright + axe + Lighthouse (package.json is for tests only)
fonts/                  Space Grotesk, Inter (SIL OFL 1.1)
media/intro/            the approved logo animation (as supplied, unchanged)
media/logo/             header lockup, keyed from that animation
media/flight/           flight.json, film clips, plate, Hero stills (16:9 and portrait), fog
media/work/             project images, copied unchanged from each project (see below)
tools/                  build-flight-media.sh, extract-logo-assets.py
```

`media/flight/` is generated by `tools/build-flight-media.sh` from the Higgsfield jobs listed at the top of that script. It needs network access to `d8j0ntlcm91z4.cloudfront.net`.

Run locally:

```
python3 -m http.server 8765 --directory aik-site
```

## The opening

| Beat | Source | What happens |
|---|---|---|
| Logo | `media/intro/aik-logo-intro.mp4` | Plays once, unchanged. If it cannot play, the console says so, `data-intro="logo-failed"` is set and the opening starts at the film; nothing stands in for the logo |
| Light reveal | logo last frame + mountain plate (eagle-free) | A band of light crosses the letters; the mountains appear inside them |
| Into the scene | same | The letters open up into the landscape |
| Film | `flight.json` → `film` | Eagle flies in → approved eagle shot → recedes into the valley → camera settles on the Hero |
| Pull-back (phones) | portrait Hero | From the last film frame back to the full-screen portrait Hero |
| Hero | `hero.webp` / `hero-portrait.webp` | STUDIO under the glass letters, then the nav |
| Scroll | Hero + two real fog plates | Gentle push, fog at two speeds, darkness, next block (`#work`) |

A "Skip intro" button is available while the opening plays; scrolling also skips it. Reduced motion or no script: the Hero still with STUDIO and the nav.

### Replacing the eagle footage

The film is a list in `media/flight/flight.json`:

```json
"film": [
  {"src": "flight/entry.mp4"},
  {"src": "flight/eagle.mp4", "from": 2.5417},
  {"src": "flight/dive.mp4", "from": 0.0417, "to": 6.25, "rate": 1.33},
  {"src": "flight/settle.mp4", "from": 0.0417, "framing": "hero", "titleBeforeEnd": 2.0}
]
```

Each clip plays from `from` to `to` (seconds, default: whole clip) at `rate`. Durations and sizes are read from the files, so a final eagle video replaces a temporary one by changing its `src` (or the file). The last clip should end on the Hero frame (`framing: "hero"`); `titleBeforeEnd` sets when STUDIO appears.

### Phones

The phone Hero is `hero-portrait.webp`: a 9:16 extension of the approved Hero (Higgsfield 9f97bbe7, sky above and clouds below) with the approved pixels pasted back over its middle. `heroPortrait.inner` in `flight.json` records where that original frame sits, so the film lines up with it.

## Selected Work

Since 25 October MA'LOA is the only visual case (owner decision): full-width name, Lanai as the lead photograph, Spicy Tropical as a smaller second frame, facts and note. Their former layouts are archived in `docs/aik-studio/archive/selected-work-three-projects-v6.html`; images and CSS stay in place. No links: none of the projects has a verified live address.

## Tests

```
npm install            # once: Playwright 1.56, axe-core, Lighthouse (dev only)
npm test               # EN/DE × 1440, 1024, 768, 390, 375 + behaviour + axe
npm run test:visual    # screenshots → tests/output/
npm run serve & CHROME_PATH=/opt/pw-browsers/chromium-1194/chrome-linux/chrome npm run audit:lighthouse
```

Without `media/flight/`: `AIK_MEDIA_OPTIONAL=1 npm test`. With the film but
without the original logo files: `AIK_MEDIA_OPTIONAL=logo`.
